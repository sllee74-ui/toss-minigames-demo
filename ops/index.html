전국민의 미니게임 · 운영 설정

앱을 다시 출시하지 않고 경제 수치를 바꾸는 페이지입니다. 단위는 코인(10코인 = 토스 포인트 1원)입니다. 저장하면 GitHub에 기록되고 약 1~2분 뒤 배포됩니다. 잘못된 문서가 올라가면 자동 검증이 직전 정상본으로 되돌립니다.

먼저 읽어 주세요 — 이 페이지가 안전한 이유

  • 앱에 박힌 허용 범위가 최종 방어선입니다. 각 항목 옆의 범위를 벗어난 값이 하나라도 있으면 앱은 문서 전체를 무시하고 마지막 정상 설정으로 계속 동작합니다. 이 페이지와 자동 검증은 실수를 미리 잡아 줄 뿐입니다.
  • 대부분의 값은 "다음 날 05:00"부터 적용됩니다일 단위. 하루 중간에 캡·횟수·보상 금액이 바뀌면 같은 날 유저마다 규칙이 달라지기 때문입니다. 앱은 그날 처음 연 시점의 값을 05:00까지 고정합니다.
  • 즉시 적용은 "적립 일시 중단" 하나뿐입니다즉시. 긴급 정지용입니다.
  • 전파 시간: 저장 → 배포 1~2분 → 인터넷 캐시 최대 10분 → 유저가 앱을 새로 열거나 다른 앱에 갔다 돌아올 때 반영됩니다.
  • 라이브 / 테스트: 테스트 문서는 QR 테스트 빌드만 읽습니다. 실험은 테스트에서 먼저 하세요. 라이브 유저에게는 영향이 없습니다.
  • 모든 저장은 기록이 남습니다(변경 이력 · 배포 상태). 되돌리려면 예전 값을 다시 저장하면 됩니다.

GitHub 토큰

토큰은 이 탭에만 보관되고 탭을 닫으면 지워집니다(같은 주소의 다른 페이지가 읽지 못하게 하기 위함). 토큰 없이도 현재 값은 볼 수 있습니다.

토큰 만드는 법 (처음 한 번)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → toss-minigames-demo 하나만
  3. Permissions → Repository permissions → Contents: Read and write (다른 권한은 주지 마세요)
  4. 만료일은 90일 이하 권장. 만들어진 토큰을 위 칸에 붙여 넣습니다.
  5. 이 저장소의 루트는 게임물 등급분류용 웹 데모입니다. 이 페이지는 ops/ 폴더의 설정 문서만 고칩니다 — GitHub에서 다른 파일을 직접 수정하지 마세요.
  6. GitHub 계정에 2단계 인증을 꼭 켜 두세요 — 이 계정이 곧 토스 포인트 지급 스위치입니다.

⏸ 적립 일시 중단 즉시

켜면 모든 코인 적립(게임·타임 보너스·에너지 보상·출석·알림 동의)이 멈춥니다. 토스 포인트로 받기는 계속 됩니다.

자세히 — 언제·어떻게 동작하나
  • 광고를 보기 전에 막힙니다. "광고를 봤는데 0P"는 생기지 않습니다(정책상 금지). 이미 광고를 재생 중이던 유저의 그 1회는 정상 지급됩니다.
  • 앱 홈에 "잠시 적립이 멈췄어요" 안내가 뜨고, 게임·장치 버튼이 사유와 함께 잠깁니다. 문구는 앱에 고정돼 있어 여기서 바꿀 수 없습니다.
  • 반영 시간: 저장 후 최대 약 10분 + 유저가 앱을 다시 열거나 돌아올 때. 앱을 계속 켜 둔 유저는 그만큼 늦을 수 있습니다.
  • 언제 쓰나: 지급이 비정상적으로 많을 때, 프로모션 예산이 바닥났을 때, 보상 관련 버그가 의심될 때.
  • 더 강한 수단이 필요하면 앱인토스 콘솔의 긴급 점검(앱 진입 자체 차단)을 쓰세요.

  • 랭키 복권 — 본질이 확률형(뽑기)이라 꺼 두었습니다. 앱인토스 정책상 게임 앱은 확률형·랜덤 보상을 토스 포인트 프로모션과 결합할 수 없습니다. 같은 이유로 모든 보상은 고정 금액입니다.
  • 재화 이름·단위(코인, 10코인 = 1원) — 자체 재화에 '포인트' 명칭을 쓸 수 없다는 정책 때문에 정한 값이라 앱에 고정했습니다.
  • 타임 구간(아침 05~11 / 점심 11~17 / 저녁 17~05)과 하루 시작 시각 05:00 — 중간에 바꾸면 날짜 계산이 어긋나 출석이 두 번 되거나 연속 출석이 끊깁니다.
  • 1회 전환 한도 350원 — 앱인토스 콘솔 프로모션의 "1회 최대 지급 금액"과 반드시 같아야 합니다. 다르면 전환이 실패합니다.
  • 광고 ID·프로모션 코드 — 심사 대상 값입니다. 잘못 바꾸면 반려되거나 수익이 다른 앱으로 귀속됩니다.
